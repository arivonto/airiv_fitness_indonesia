AIRIV Active Wellness

Adaptive Fitness & Wellness Operations Platform

Human-centered fitness workspace for Odoo 18 with member and trainer records, membership plans, energy-aware assessments, explainable wellness scoring, and progress journeys.

Odoo 18 CommunityFitnessWellnessProgressAIRIV

Core Capabilities

AIRIV Active Wellness turns Odoo into a practical fitness operations workspace that connects membership, coaching, assessments, and measurable progress.

Membership

Plans and members

Manage members, trainers, membership plans, active periods, and relationship context.

Wellness Assessment

Energy-aware scoring

Capture assessment signals and produce an explainable wellness score for coaching review.

Progress Journey

Goals and tracking

Keep progress milestones, check-ins, coaching notes, and next actions visible over time.

Feature & Workflow Automation

1

Set up plans

Create membership plans, durations, benefits, and trainer responsibilities.

2

Register member

Create member and coach records, then assign the appropriate plan and period.

3

Assess wellness

Record energy-aware assessment inputs and review the explainable score.

4

Track progress

Update milestones, coaching notes, and next actions across the member journey.

Installation Guidance

Install

Add to Odoo addons

Clone branch 18.0, place the module on the addons path, restart Odoo, update the Apps list, and install.

Configure

Set wellness context

Configure membership plans, trainers, assessment fields, and operational access groups.

Operate

Run member journey

Register members, assess wellness, record coaching, and update progress milestones.
